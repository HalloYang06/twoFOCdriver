# 修改记录

## 2026-04-17

### 提交主题
- EtherCAT 初始化失败路径补全 + LAN9252 IRQ/SYNC 引脚编译期强校验

### 修改文件
- `comm/protocol/comm_ecat_if.c`
- `BSP/bsp_lan9252.c`

### 变更内容
1. `comm_ecat_if_init()` 现在检查 `CiA402_Init()` 返回值。
2. `comm_ecat_if_init()` 现在检查 `APPL_GenerateMapping()` 返回值。
3. 上述任一失败时，置 `g_ecat_failed=1` 并保持 not-ready。
4. `bsp_lan9252.c` 移除 IRQ/SYNC0/SYNC1 的 0 默认值。
5. 若未定义 `BSP_LAN9252_IRQ_* / SYNC0_* / SYNC1_*` 宏，编译期 `#error` 直接报错，避免中断链路静默失效。

### 说明
- 本次只修 EtherCAT 实现层审查问题，不引入控制逻辑。

## 2026-04-17（补充）

### 提交主题
- EtherCAT 配置有效性与初始化健康态修正

### 修改文件
- `BSP/bsp_lan9252.c`
- `comm/protocol/comm_ecat_if.c`

### 变更内容
1. 对 `BSP_LAN9252_IRQ_Pin / SYNC0_Pin / SYNC1_Pin` 增加编译期非 0 校验。
2. `bsp_lan9252_init()` 增加 IRQ/SYNC 端口与引脚的运行时有效性检查，避免静默初始化成功。
3. `g_ecat_health_ok` 初始值改为 `0`。
4. `comm_ecat_if_init()` 所有失败路径统一将 `g_ecat_health_ok` 置 `0`，避免初始化失败时被误报健康。
