## 2026-04-17（风险修复批次）

### 范围
- `comm/protocol/comm_ecat_if.c`

### 修复项
1. 自愈重启前增加资源清理：
   - 设置 `bRunApplication = FALSE`
   - 调用 `CiA402_DeallocateAxis()` 后再执行 bootstrap
2. bootstrap 部分失败回滚：
   - `CiA402_Init()` 成功但 `APPL_GenerateMapping()` 失败时，执行 `CiA402_DeallocateAxis()`
3. 修复 `mode_display` 语义不一致：
   - `objModesOfOperationDisplay` 改为写入 `mode_display`
4. 增加 not-ready 周期重试初始化：
   - `comm_ecat_if_process()` 中每 1000 tick 触发一次 `comm_ecat_if_init()` 重试

### 代码分析
1. 初始化返回值风险：
   - `comm_ecat_stack_bootstrap()` 已显式检查 `MainInit/CiA402_Init/APPL_GenerateMapping`，失败即返回 0，不会误置 ready。
2. 自愈重启资源风险：
   - 原流程可能重复执行 CiA402 初始化并累积资源；现在加入重启前清理与部分失败回滚，避免长期资源退化。
3. 初始化永久熔断风险：
   - 通过 not-ready 周期重试，瞬时故障恢复后可自动再次初始化，无需重启系统。
4. TXPDO 接口一致性：
   - `mode_display` 计算结果与最终写回字段统一，避免接口语义漂移。
